# Vantis-X

Vantis-X is a high-performance fixed-wing UAV with a custom-designed flight controller. The aircraft is designed to be fully 3D-printed, with a focus on lightweight construction and integrating the airframe and electronics into one system.

**Development journal:** [JOURNAL.md](https://github.com/Zoomwag/Vantis-X/blob/main/JOURNAL.md)

![Vantis-X aircraft CAD](https://github.com/user-attachments/assets/c815ed0f-c3b6-4f28-947f-b8f4c873e34a)

The aircraft has a wingspan of approximately 1 metre and an estimated all-up weight of 450 g. The design is still in development, with the airframe and flight controller being developed alongside each other.

## Flight Controller

The flight controller is being designed specifically for Vantis-X rather than using an off-the-shelf board. This includes the schematic, component selection, PCB layout and 3D modelling before manufacture.
